# LifeLoop「回响」情绪体验前端

React + TypeScript + Vite。当前版本依据 LifeLoop v3 r02 制作，产品主线是情绪记录、理解卡、当日日记和带来源的跨时间回响。

## 开发

在 `frontend` 目录运行：

```powershell
pnpm install
pnpm dev
```

浏览器打开 `http://127.0.0.1:5173/`。使用 `pnpm build` 检查 TypeScript 并构建。

## 2026-09-10 当前范围

- 四页视觉与流程骨架：记录、记忆、日记、回响。四页共用柔和、温暖、克制的设计语言，但采用不同的信息结构。
- 记录页支持手输或粘贴、事件日期、2000 字限制、默认仅保存，以及单独的“AI 帮我整理本条”入口。
- “仅保存”只更新页面内存，不触发理解卡；点击整理后才显示明确标为合成草稿的 EmotionCard。
- EmotionCard 展示事件、可并存/自填/清空的情绪、状态角标和可折叠的触发/想法/行为；已确认样例可点击情绪核对原文片段。
- 记忆页支持情绪筛选、原文/事件搜索、完整原文、来源和候选权限展示。
- 日记与回响目前是后续任务的可评审布局草稿，尚未实现真实生成、保存与授权执行。
- 用户昵称使用“小响”，导航为弹出抽屉；Esc 与遮罩可关闭。
- 全部数据为合成数据，只存在当前页面内存，刷新后重置；不连接后端、AI、账号或私人记录。

## 人工走查

1. 空正文点击“仅保存”或“AI 帮我整理本条”，确认页面阻止继续并保留输入。
2. 输入文字并点击“仅保存”，确认记录加入最近片段且不出现理解卡。
3. 输入文字并点击“AI 帮我整理本条”，确认仅在主动点击后出现合成理解卡。
4. 修改事件或清空情绪；展开触发、想法与行为；分别检查“不采用”和“确认”。
5. 进入记忆页，切换情绪筛选、搜索事件，并选择记录查看完整原文。
6. 点击已确认记录的具体情绪，确认展示对应原文片段；用户已修改的记录不显示 AI 来源校验标签。
7. 打开菜单，检查昵称“小响”和四页入口；按 Esc 或点击遮罩关闭。
8. 缩小到手机宽度，确认单列布局、控件换行且正文可读。
